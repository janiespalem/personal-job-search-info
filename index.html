Personal Job Search

A private, locally hosted job-application tracker maintained by Fiodar Pysh, based on JobNavigator.

The Gmail connection helps the owner identify recruiter replies and match them to recorded applications. It uses read-only access to retrieve relevant messages and track recruitment updates.

Personal use

This installation is for its owner's own job search. It is not a public email service and does not accept public sign-ups. This website contains product and privacy information only; the application and its database run on the owner's computer.

Gmail access

Google handles sign-in and permission approval. The application does not receive the Google account password. The requested Gmail permission is read-only: it cannot send, edit or delete messages in Gmail.
