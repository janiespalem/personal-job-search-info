Privacy policy

Effective date: 17 November 2026. This policy describes Fiodar Pysh's personal, locally hosted Personal Job Search installation.

Information accessed and purpose

With the account owner's consent, the application requests https://www.googleapis.com/auth/gmail.readonly. This permission allows reading mailbox data; the application uses Gmail search to retrieve messages relevant to job applications. Data processed can include the account email address, message and thread identifiers, sender, subject, dates, labels and message body text. It uses this information to identify recruitment replies and associate them with recorded applications.

The Gmail connection cannot send, modify or delete Gmail messages. Google handles authentication; the application does not collect the Google account password.

Storage and access

OAuth credentials and refresh tokens are stored in the owner's local configuration and application database. Processed message identifiers, recruitment outcomes, response excerpts or summaries, and application records may be retained locally. Local backups may also contain these records. Access is controlled by the owner's operating-system and application permissions. Requests to Google's APIs use HTTPS.

Sharing and limited use

Gmail data is not sold, used for advertising, or published on this website. External language-model processing and application telemetry are disabled in this installation. Gmail content is not sent to external model providers or used to train models. Any change to that practice requires a policy update and the owner's explicit consent before processing changes.

Personal Job Search uses Google API data solely to provide the described job-application tracking features. Its use and transfer of Google API data follow the Google API Services User Data Policy, including its Limited Use requirements.

Retention, disconnection and deletion

Local recruitment records remain until the owner deletes them; there is no automatic time-based deletion guarantee. Disconnecting Gmail in application settings removes the stored connection token, but does not automatically remove existing application records or backups. The owner can revoke access through Google Account connections, and delete retained local records and relevant backups. Revocation prevents further authorized Gmail access but does not erase previously stored data.

This website and contact

These static informational pages are hosted by GitHub Pages. They contain no mailbox data, login form, tracking scripts or analytics. GitHub may process website access information under its own privacy statement.

This app is operated for personal use by Fiodar Pysh. For questions, use the contact information on the maintainer's GitHub profile. Do not post private email contents in public issues.
